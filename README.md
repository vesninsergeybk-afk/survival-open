# Выживший / Survival Open

Публичный репозиторий браузерной игры «Выживший».

**Статус:** перенос исходников и ресурсов из закрытого проекта выполняется. Пока состав файлов и проверка лицензий не завершены, эта ветка не является готовой к публикации сборкой.

Исходная игра: `vesninsergeybk-afk/Timeweb`, каталог `site/games/survivor/`, ветка `production`. Действующая публикация пока остаётся без изменений.

## Лицензии

В игре используются собственные материалы, исходный код под MIT, ресурсы CC0 и CC BY 4.0. Некоторые аудиоматериалы Sonniss распространяются по отдельной лицензии, которая не допускает свободную раздачу исходных звуков. Их публикация в открытом репозитории требует отдельного решения.
