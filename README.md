# Выживший / Survival Open

Публичный репозиторий браузерной космической игры «Выживший».

**Основной игровой режим:** [бесконечная аркада](arcade/) — корабль с инерцией, добыча ресурсов, развитие вооружения, союзные станции и звенья, вражеские базы. Стартовая `index.html` открывает аркаду. Предыдущая версия сохранена в `legacy-game.html`, пролог — в `prologue/`.

## Состояние переноса

Исходная рабочая версия: `vesninsergeybk-afk/Timeweb`, `production`, `site/games/survivor/`; контрольный коммит `539cd7f13f15519fbe1ff2b2589bf0a4fae306f1` от 3 ноября 2026 года.

Из 595 исходных файлов перенесены и проверены по контрольным суммам 569. Не опубликованы 26 отдельных студийных аудиозаписей Sonniss: лицензия разрешает их использование в готовой игре, но ограничивает распространение исходных звуков. Текущая аркада не ссылается непосредственно на эти записи. Подробнее — [статус переноса](MIGRATION_STATUS.md).

Новые изменения в исходной ветке после контрольного снимка надо переносить отдельно, проверяя их слияние с текущей аркадой. Старый сайт пока не переключён.

## Локальная проверка

Для запуска используйте локальный HTTP-сервер из корня репозитория, например:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для проверки игровой логики:

```bash
node --test arcade/tests/*.test.mjs
```
