# Выживший / Survival Open

[Полная сверка последнего этапа разработки](arcade/WHOLE-GAME-REVIEW-2026-11-04.md): 31 исходный пункт, 32 поздних уточнения, состояние кода и исправленный порядок дальнейших работ.

Публичный репозиторий браузерной космической игры «Выживший».

**Основной игровой режим:** [бесконечная аркада](arcade/) — корабль с инерцией, добыча ресурсов, развитие вооружения, союзные станции и звенья, вражеские базы. Стартовая `index.html` открывает аркаду. Предыдущая версия сохранена в `legacy-game.html`, пролог — в `prologue/`.

## Локальная проверка

Для запуска используйте локальный HTTP-сервер из корня репозитория, например:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для проверки игровой логики:

```bash
node --test arcade/tests/*.test.mjs
```

## Публикация

**Единственная актуальная аркада:** https://vesninsergeybk-afk.github.io/survival-open/arcade/. Корень `https://vesninsergeybk-afk.github.io/survival-open/` перенаправляет в неё. GitHub Actions проверяет игру и публикует сборку только после обновления `main`. С основного сайта вход осуществляется через [«Лабораторию абсурда»](https://vesninmed.ru/lab/); прежняя версия в `/games/survivor/` остаётся архивной. См. [правила публикации](docs/PUBLICATION_POLICY.md).
