# Полупрозрачные туманности: Screaming Brain Studios (CC0)

Оригинальные изображения: **Screaming Brain Studios — Seamless Space Backgrounds**, https://screamingbrainstudios.com/dl-seamless-space-backgrounds/

Лицензия: **Creative Commons CC0 1.0**, https://creativecommons.org/publicdomain/zero/1.0/ . Указание автора не требуется, но сохраняется для проверки происхождения.

Оригинальный пакет: `SBS - Seamless Space Backgrounds - Small 512x512.zip`, получен с официального сайта автора; набор содержит бесшовные космические фоны в PNG.

Использованы исходные изображения (цветовая палитра адаптирована для регионов игры):

| Регион | Файл из исходного архива |
|---|---|
| 0, Аметистовая туманность | Purple Nebula 5 - 512x512.png |
| 1, Лазурный разлом | Blue Nebula 5 - 512x512.png |
| 2, Янтарные облака | Purple Nebula 3 - 512x512.png |
| 3, Лиловые глубины | Purple Nebula 7 - 512x512.png |
| 4, Бирюзовая бездна | Green Nebula 3 - 512x512.png |

**Изменения:** переработана окраска, извлечён полупрозрачный слой газовых структур, сохранена бесшовность повторения изображения, каждый 512×512 PNG преобразован в компактный WebP с прозрачностью. Исходный ZIP в приложение не включён. Сценические слои используются **поверх уже утверждённых региональных фонов**. Они не меняют карту, камеры, столкновения, музыку и интерфейс.

В игре загружается только изображение текущего региона. Если загрузка WebP не удаётся, остаются прежние процедурная дымка и фон сектора.

Скрипт воспроизводимой переработки исходных файлов: `arcade/tools/build-sbs-clouds.py`. Структура упаковки и дата переработки: 16 ноября 2026 года.

Дополнительно: `?skytexture=off` отключает только эти пять текстур, сохраняя остальные ранее действовавшие эффекты космоса. `?cosmos=off` отключает весь дополнительный модуль фоновой анимации.
