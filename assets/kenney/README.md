# Kenney Tiny series — CC0 assets

Three original 16x16 pixel-art tilemaps, used without redrawing.
- Tiny Town: https://kenney.nl/assets/tiny-town
- Tiny Dungeon: https://kenney.nl/assets/tiny-dungeon
- Tiny Farm: https://kenney.nl/assets/tiny-farm

Author: Kenney. License: Creative Commons Zero (CC0 1.0 Universal).
License reference: https://creativecommons.org/publicdomain/zero/1.0/
Attribution is not required; recorded here for provenance.

Source files: Tilemap/tilemap.png extracted unmodified from the original free ZIP files.
Each source tile is 16×16 pixels; adjacent tiles are separated by a 1px gutter.
The 203×186 image contains a grid of 12 columns and 11 rows.
Composite objects must be assembled from complete cells, never arbitrary atlas rectangles.
The index page ../asset-gallery.html displays the sources and checks source bounds.

Some grid cells form parts of larger trees/buildings: they are not independent objects.
The game's collision areas, rendering layers and animation timing remain separate from artwork.
