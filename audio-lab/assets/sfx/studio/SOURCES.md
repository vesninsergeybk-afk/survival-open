# Архив сведений о студийных звуках Sonniss

В прежней закрытой сборке «Выжившего» применялись фрагменты Sonniss
#GameAudioGDC 2026. В **нынешней открытой версии эти файлы отсутствуют,
не загружаются и не воспроизводятся**. Все активные события звуковой
библиотеки теперь связаны с записанными CC0-эффектами Kenney и звуками
баз. Никакие Sonniss OGG в GitHub Pages не включаются.

Источник: https://gdc.sonniss.com/
Условия: https://sonniss.com/gdc-bundle-license/

Предшествующий список сохранён для истории происхождения материалов.
Он не подтверждает разрешения распространять исходные WAV/OGG в публичном
GitHub или отдельной библиотеке аудиофайлов.
