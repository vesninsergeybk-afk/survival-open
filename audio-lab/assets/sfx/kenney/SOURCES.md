# Дополнительные записи Kenney CC0

В открытой сборке «Выживший» используется 36 оригинальных OGG из двух
официальных наборов Kenney:

- [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds): лазеры, щиты,
  взрывы, двигатели, электронные устройства;
- [Impact Sounds](https://kenney.nl/assets/impact-sounds): ударные и
  механические эффекты, а также добыча руды. Основной автоогонь и
  ручное вооружение теперь используют [полевые записи](../foley/SOURCES.md),
  потому что прежние файлы Kenney были созданы в GameSynth.

Автор: Kenney (https://kenney.nl/). Лицензия обоих наборов:
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Их разрешено использовать и распространять, в том числе в коммерческой игре.
Указание автора не обязательно, но сохранено здесь.

Проверяемое зеркало файлов:
https://github.com/GeorgeQLe/assets-sfx-combat

Каждая запись перечислена в [manifest.json](./manifest.json): исходное имя,
точный путь, размер в байтах и Git blob SHA-1. Исходный коммит зеркала
закреплён в манифесте; при публикации скрипт
`tools/prepare-cc0-sfx.mjs` скачивает файлы из него, проверяет размер,
контрольную сумму и заголовок Ogg. Только после этого они попадают в
GitHub Pages. Скрипт прекращает публикацию при любой ошибке.

Бинарные файлы не копируются в Git-историю этого репозитория, чтобы не
дублировать исходную библиотеку. Для локального запуска из корня
репозитория сначала выполните:

```sh
node tools/prepare-cc0-sfx.mjs .
```

Это загружает те же 36 записей на компьютер; исходные OGG не создаются
программно. При отсутствии загрузки звуковой микшер ждёт файл и
не подменяет его синтезированным эффектом.

Для кометы, минного веера, рывка и роя больше не используются записи
Kenney: их реальные пиротехнические и механические звуки перечислены
в [соседнем каталоге](../foley/SOURCES.md). Звук взведения мин по-прежнему
срабатывает один раз на весь залп.

Отдельные эффекты баз на основе CC0 перечислены в
[../base/SOURCES.md](../base/SOURCES.md). Студийные записи Sonniss в открытой
сборке не используются.
