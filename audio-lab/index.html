Звук, который чувствуется

Прослушивание индивидуальных звуков вооружения, баз, сопряжения, построек и интерфейса. Управление громкостью групп, ограничение числа одновременных звуков и приглушение музыки при мощных ударах.

Звуки из реальной игры. Пять эффектов Kenney CC0 теперь воспроизводятся из настоящих OGG (импульс, попадание, броня, малый взрыв, подбор). Ещё 29 эффектов баз — CC0. Отсутствующие 21 студийная запись Sonniss заменяются процедурным звуком; публиковать их исходники в открытом репозитории нельзя без разрешения. Базовый автоогонь по-прежнему использует специально смягчённый синтез.

Микшер

Импортированные файлы остаются только в памяти вашего браузера. Назовите файл по идентификатору из карточки (например, railgun.wav или explosion_big.ogg), чтобы заменить соответствующий черновой звук. Для музыки: music_exploration.ogg, music_combat.ogg и т. д.
