# «Выживший»: звуковая лаборатория

Обновлено 3 ноября 2026 года. Текущая версия относится к открытому
репозиторию `survival-open`, ветка `main`.

## Что подключено

- **15 звуковых вариантов вооружения**: в том числе новый тихий импульс
  для базовой автоматической пушки.
- **12 других событий**: попадания по корпусу и щиту, малые и большие взрывы,
  предупреждение и появление босса, урон, гибель, ресурсы, улучшения, достижения.
- **26 исходных студийных OGG Sonniss** отсутствуют в открытом репозитории;
  соответствующие игровые события используют синтезированные замены.
- Источник: [Sonniss #GameAudioGDC 2026](https://gdc.sonniss.com/).
  Лицензия для игр: [Sonniss Game Audio Bundle v2.0](https://sonniss.com/gdc-bundle-license/).
  Все использованные исходники и особенности обработки:
  [studio/SOURCES.md](./assets/sfx/studio/SOURCES.md).
- В прежней закрытой версии Timeweb использовались сокращённые студийные
  эффекты. Открытая версия не распространяет эти записи. Права на
  Sonniss-звуки остаются отдельными от лицензии MIT на исходный код.
- Для базовой автоматической пушки специально создан мягкий процедурный
  сигнал, рассчитанный на многократные повторы. При непрерывном огне он
  постепенно приглушается; после паузы первое срабатывание заметнее.

## Звуковой баланс

Звуки разделены на пять групп: оружие, попадания, интерфейс, окружение и музыка.
Микшер работает через Web Audio, мягко ограничивает динамику и убирает
излишне резкий верх в оружейном диапазоне. Одновременно звучат не более
12 голосов, из которых не более пяти — выстрелы и не более трёх — попадания.
Повторы одного события ограничены по времени: у быстрого импульса, рельсотрона,
ауры и орбитальных спутников разные интервалы.

Мощные взрывы и опасные события получают приоритет и кратковременно
приглушают музыку. Рельсотрон и большие взрывы имеют отдельный низкий
ударный слой; звуки частых попаданий заметно тише.

## Музыка

В игре используется лицензированный кинематографический саундтрек
Scott Buckley (CC BY 4.0 с указанием автора):

- `Starfire` — исследование космоса.
- `Pursuit` — интенсивный бой.
- `Eyes in the Void` — сражение с боссом.

Переходы занимают несколько секунд. Музыка загружается по мере необходимости,
без полного декодирования многоминутных треков в память телефона.
Подробности: [музыкальные лицензии](../assets/audio/music/CREDITS.md).

Лаборатория поддерживает локальный импорт собственных WAV/OGG/MP3, включая
композиции с именами `music_exploration.ogg` и `music_boss.ogg`. Импорт
не загружает файлы на сервер, это временное сравнение в браузере.

## Проверка

1. Открыть [звуковую лабораторию](./) и нажать **«Включить звук»**.
2. Прослушать все виды оружия по одному и проверить характер атаки.
3. Нажать **«Проверить бой: 8 событий»** и проверить разборчивость микса.
4. Открыть [игру](../), включить звук и сыграть с разными видами вооружения.
5. Проверить на телефоне, в наушниках и на обычных динамиках: сильные удары
   не должны искажаться, частые попадания не должны сливаться в шум.
6. Для проверки исходного кода локально:
   `node audio-lab/smoke-test.mjs`.

В открытом репозитории `survival-open` GitHub Actions проверяет код и
публикует игру из ветки `main` через GitHub Pages.
