# Звуковая библиотека «Выжившего»

Обновление: 8 ноября 2026 года. Источник истины —
публичный репозиторий `survival-open`, ветка `main`.

## Активная библиотека

Все игровые события в `audio-lab/sound-map.js` указывают на OGG-файлы.
В публичной версии используются:

- 36 дополнительных записей Kenney CC0 (часть создана в GameSynth);
- 5 записей Kenney CC0, уже входивших в игру;
- 28 отдельных полевых записей пиротехнических и механических звуков CC0
  для автоогня, кометы, мин, рывка и роя;
- 29 CC0-звуков для строительства и развития баз;
- 12 композиций Scott Buckley по CC BY 4.0.

Участок кода, который создавал звук колебаниями генераторов и шумом
Web Audio, отключён. Сначала автоогонь использовал четыре готовых лазерных файла. Они не
синтезировались во время игры, но звучали как электронные «пищалки».
После повторной проверки 8 ноября основной автоогонь сочетает пять пар
коротких полевых записей: пиротехнический хлопок либо механический удар,
поддержанный вторым тихим ударом. Прежние файлы были созданы в GameSynth;
новые исходники этой цепочки записаны в реальном мире. Для противников, ракет, сильных
взрывов и попаданий предусмотрены другие записи. Звуки пользовательского
интерфейса, станций, добычи и смены боевой обстановки тоже используют
каталог записей.

**Если запись ещё не загрузилась, звук временно не воспроизводится.**
Вместо него не включается синтезатор. По мере загрузки игра начинает
воспроизводить подходящие файлы, не прерывая управление кораблём.

## Как публикуются файлы

Дополнительные OGG берутся из открытого зеркала наборов Kenney, закреплённого
на конкретном коммите. При каждом запуске GitHub Pages сборщик загружает
36 файлов, проверяет их размер и Git SHA-1 и включает в сайт только
после успешной проверки. Это позволяет не копировать исходные бинарные
файлы в Git-историю проекта. Если источник недоступен или файл изменён,
публикация останавливается с ошибкой.

Списки и лицензии: [Kenney](./assets/sfx/kenney/SOURCES.md),
[записанные эффекты боя](./assets/sfx/foley/SOURCES.md).
Звуки баз: [CC0](./assets/sfx/base/SOURCES.md).
История ранее использовавшихся студийных эффектов:
[Sonniss](./assets/sfx/studio/SOURCES.md); в нынешней игре их нет.

Для локальной разработки один раз загрузите звуки из корня проекта:

```sh
node tools/prepare-cc0-sfx.mjs .
python3 -m http.server 8000
```

При запуске с GitHub Pages дополнительная команда не нужна: записи уже
включены в опубликованный сайт.

## Сведение и поведение

Web Audio разделяет оружие, попадания, интерфейс, станции и окружение.
Общая громкость, уровни отдельных групп и музыка регулируются независимо.
При крупных взрывах музыка на короткое время приглушается, итоговый уровень
ограничивается компрессором. Число одновременно звучащих эффектов
ограничено: максимум 12, для оружия — 5, для попаданий — 3.

Близкие выстрелы слышны отчётливее далёких. При долгом автоматическом
огне импульсы постепенно приглушаются, чтобы не утомлять игрока. Для
экстрактора используется одна непрерывная звуковая запись, которая
запускается при удержании клавиши и плавно затухает после отпускания.
Меню, тревога, открытия и строительные события используют
редкие короткие сигналы.

## Музыка

12 произведений Scott Buckley распределены по группам: начало игры,
исследование, тревога, бой и штурм. При развитии угрозы музыкальный
режиссёр меняет группу, делая переход за несколько секунд. Треки
передаются потоково, чтобы не декодировать одновременно десятки мегабайт
на мобильном устройстве. Лицензии:
[атрибуция Scott Buckley](../assets/audio/music/CREDITS.md).

## Проверка

1. Откройте [звуковую лабораторию](./), включите звук и дождитесь появления
   отметок загрузки у карточек.
2. Сравните пять вариантов основной пушки с тяжёлыми выстрелами,
   взрывами и звуками попаданий.
3. Запустите демонстрацию восьми боевых событий, затем послушайте
   звуки интерфейса, окружения и добычи.
4. Откройте [игру](../arcade/), включите звук и проверьте продолжительный
   автоогонь, ракеты, разрушение астероидов, удержание и отпускание
   экстрактора, переключение вкладок, взрывы, базовые действия и музыку.
5. Проверьте на телефоне и компьютере: нет треска, резкой разницы
   громкости или бесконечного наложения одного сигнала.

Программная проверка:
`node audio-lab/smoke-test.mjs` и
`node --test arcade/tests/*.test.mjs`.
