# Новые смысловые значки меню развития

Пять самостоятельных векторных изображений: `dodge.svg`, `extractor.svg`, `wreck.svg`, `capture.svg`, `signal.svg`. Каждое представляет **отдельный реальный навык**. До этой правки их подменяли рисунками двигателя, добычи, корпуса, энергоядра и помехи.

- `dodge`: манёвр корабля между следами движения.
- `extractor`: механический экстрактор и руда.
- `wreck`: фрагменты брони как временное укрытие.
- `capture`: перехват управления выбранной целью.
- `signal`: антенна и раскрытый сигнал патруля.

`branch-variants.svg` — 16 самостоятельных символов через `<symbol>`: по два пути для каждого из четырёх семейств автоматического оружия и четырёх тактических устройств. Они накладываются поверх **существующего** изображения оружия/устройства. Дополнительные SVG не создают новые навыки и не изменяют цены, требования или обработчики действий.

## Отображение

`progression-screen.js` назначает значок через `iconFor`; путь развития показывает соответствующий `variant` через `<use href="...#id">`. Варианты скрыты от скринридера, потому что полное название и текущий статус каждого пути остаются видимым текстом и `aria-label`.

Рамки и состояния узлов по-прежнему берутся из `assets/progression/frames`, а реальные зависимости рисует `paintProgressionLinks`. Не рисуйте в изображениях цены, соединения, проценты, уровни или признаки доступности.

Все SVG: прозрачная подложка, ограниченная палитра стали, матовой бирюзы и тёплого янтаря, без надписей и внешних шрифтов. Для небольших размеров использованы крупные силуэты и широкие контуры.

## Проверка

`node --test arcade/tests/*.test.mjs` проверяет существование файлов, соответствие 16 ветвей реальной модели и наличие безопасных HTML-ссылок на символы. Для утверждения визуального качества остаются необходимые браузерные проходы на 1440×900, 1280×720, 844×390, 932×430, 390×844 и 360×640: значки должны различаться не только по цвету, не перекрывать названия или кнопки и не добавлять прокрутку страницы.
