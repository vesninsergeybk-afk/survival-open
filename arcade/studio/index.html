    Звуки здесь описаны словами, но не воспроизводятся: это отдельная задача звукового стенда. Эффекты показаны упрощённо и не подменяют реальные столкновения, урон, ИИ и анимации игры. При системном ограничении движения анимация сокращается.

    VFX / A–B / РЕАЛЬНЫЕ АССЕТЫ

    Сравнение двух визуальных решений

    Отдельные гипотезы для добычи, щита, корпуса, ракет, крупных кораблей и орбитальной атаки. Оба варианта экспериментальные; утверждённым считается только результат проверки в игре.

    Здесь показывается специализированный стенд внутри общей мастерской. Прежний адрес лаборатории теперь ведёт в этот раздел; отдельного второго каталога концепций больше нет.

    КОНТРАКТ КАЧЕСТВА

    Четыре согласованных направления

    Для каждого решения фиксируем цель, наблюдаемое поведение, критерий готовности и ближайшую проверку. Изменение визуала само по себе не считается улучшением геймплея.

    Заметки к следующей итерации

    Можно дописать свои идеи. Они сохраняются только в этом браузере, не изменяют GitHub и не попадают в игру автоматически.

    ГОТОВЫЕ ИНСТРУМЕНТЫ

    Стенды, которые уже есть

    Сохраняем прежние проверки и не переделываем их заново. Новая мастерская связывает результаты, а специальные стенды остаются самостоятельными.
