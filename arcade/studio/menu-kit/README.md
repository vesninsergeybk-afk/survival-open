# Графика игровых меню v2

Эти элементы принадлежат действующей аркаде и не образуют отдельный игровой выпуск.

## Состав

- `orbit-engraving.svg` — векторный фон технической схемы, применяется с низкой непрозрачностью в сводке станции и конструкторе корабля. Не является картой мира и не показывает точные координаты.
- `mission/corridor.webp` — образ электромагнитного глушителя для «Глухого коридора».
- `mission/probe.webp` — повреждённый разведывательный зонд для «Последнего сигнала».
- `mission/relay.webp` — ретранслятор для операции обороны.
- `mission/carrier.webp` — транспорт с охранением для операции перехвата снабжения.

Четыре WebP — созданные генеративной моделью **предметные иллюстрации**, не снимки игрового мира и не достоверные изображения масштаба, координат, конкретного противника или его характеристик. Они отображаются только как приглушённые фоны карточек. Текст, цены, этапы, награды, кнопки и координаты всегда берутся из кода игры.

Размер каждого изображения: 1000×563; подготовлены из исходных PNG, качество WebP 78. Общий размер четырёх WebP — около 117 КБ. Для меню изображения загружаются браузером по CSS-ссылкам только при наличии карточки.

## Задание для генеративной модели

**Режим:** встроенная генерация изображений, категория `stylized-concept`, по одному изображению на операцию.

**Общая часть:** широкая иллюстрация для экрана операции двухмерной космической игры; качественная рисованная 2D-графика, читаемый силуэт, тёмное фиолетовое пространство, голубые и бирюзовые огни, сдержанные янтарные сигналы опасности. Вид сверху под небольшим углом, объект в правой половине, затемнённая левая половина предназначена для живого текста интерфейса. Без текста, букв, цифр, кнопок, рамок, водяных знаков и не относящихся к задаче объектов.

**Содержание каждого изображения:**

1. `corridor`: промышленный глушитель с двумя кольцевыми антеннами, защищённым ядром, слабыми электромагнитными волнами и далёким охранением.
2. `probe`: небольшой повреждённый зонд с аварийным маяком и согнутой антенной возле исследовательского сооружения.
3. `relay`: коммуникационная башня с антеннами и радиотарелками на небольшой скальной платформе; вдали приближаются враждебные силуэты.
4. `carrier`: бронированный грузовой транспорт со спутниками-истребителями; бронированный нос, двигатели с кормы, ощущение движения по маршруту.

## Проверка

Каждое изображение просмотрено до включения. Оно не используется в качестве источника игровых фактов. Техническую читаемость текста поверх изображений необходимо проверить в настоящем браузере, включая телефон в альбомной ориентации; один только просмотр исходного WebP этого не подтверждает.
