# I.R.I.S. («Зрачок») — восстановленный стенд спрайтов

Дата: 2026-11-04. Спрайты подключены к вражеским разведчикам в основном игровом цикле; стенд остаётся самостоятельным.

## Что сохранено
- `assets/iris-drone/iris-body.webp` — 480×480, сетка 3×3, 9 положений бронепластин; кадр 160×160.
- `assets/iris-drone/iris-ion.webp` — 960×320, сетка 6×1, 6 уровней ионной тяги; кадр 160×320.
- `iris-drone-preview.html` — независимый Canvas 2D просмотрщик, 1–200 дронов, ручной выбор положения, открытие/закрытие, двигатели, FPS.

При подготовке атласов удалены мелкие отсоединённые пиксельные артефакты по альфа-каналу. Геометрия самих девяти положений и шести струй не перерисовывалась. Заявленное качество следует проверять визуально на разных фонах.

## Проверка
Локально, из корня репозитория:
```sh
python -m http.server 8080
```
Открыть `http://localhost:8080/arcade/studio/iris-drone-preview.html`.

1. Выключить «Раскрытие / закрытие» и перебрать кадры 0–8; проверить, сохраняется ли центр и нет ли обрывов контура.
2. Включить двигатели и пройти уровни 0–5: три струи должны исходить из трёх нижних сопел.
3. Проверить 24–40 px на тёмном и светлом фоне, чтобы увидеть остаточные светлые/красные ореолы. В стенде сейчас тёмный фон; светлый фон — отдельная контрольная проверка.
4. Установить 100 и 200 дронов; зафиксировать FPS и устройство, отдельно проверить при включённых/выключенных двигателях.
5. Открыть игру и убедиться, что новая графика используется для обычных разведчиков. Для возврата к прежним спрайтам открыть игру с параметром `?iris=0`.

## Подключение к игре

В `arcade/visuals.js` внешний вид I.R.I.S. включён по умолчанию для обычных вражеских `scout`:

- По умолчанию и с `?iris=1` — корпус I.R.I.S.: первое раскрытие длится 0,9 с, затем створки периодически закрываются и раскрываются прямо во время боя; двигатели меняют длину струй при разгоне и повороте.
- С `?iris=0` — прежние анимированные разведчики. Это быстрый способ сравнения и отката без изменения кода.
- Другие классы врагов, их ИИ, урон, здоровье, радиусы столкновений и награды не изменены.
- Два дополнительных атласа загружаются только после первого отображения I.R.I.S. при включённом параметре. Пока изображения не загрузились, используется исходный спрайт. Новые материалы не загружают ИИ и не меняют игровой генератор случайных чисел.
- Пользователь сообщил, что после испытаний торможения не наблюдает; точные измерения FPS на устройстве не передавались. Облачный браузер показывал около 1 FPS даже с одним дроном и не подходит для оценки производительности на телефоне.

## Повторяющаяся анимация разведчика

В игре (`arcade/iris-drone-renderer.js`) после первого раскрытия створки каждые примерно 3,5–4,5 с проходят полный цикл: открыто → закрытие → короткая пауза → раскрытие. Время отличается по серийному номеру, поэтому стая не движется синхронно. При резком изменении направления или ускорении дрон дополнительно ненадолго прикрывает центральный механизм.

Ионная тяга включается независимо от положения створок. Из шести изображений выбирается уровень по скорости, ускорению и резкости поворота; небольшое колебание длины струй заметно и при ровном полёте. При остановке струи исчезают. Всё рассчитывается по времени и уже существующему движению разведчика: новых действий для ИИ, случайных чисел, столкновений и дополнительных изображений нет.

Если включено уменьшение анимации, створки остаются раскрытыми и мерцание тяги отключается. Самостоятельный стенд позволяет проверять изображения и нагрузку, но игровую частоту закрытия и манёвры нужно оценивать в самой игре.

Игра и стенд публикуются через GitHub Pages. При включённом `?iris=0` атласы I.R.I.S. не загружаются.

## Ограничения
- Дрон представлен фронтальным изображением, без настоящего поворота в 3D.
- Раскрытие зашито в 9 рисованных кадров; бронепластины не анимируются как отдельные объекты.
- Шесть изображений тяги — уровни мощности, а не самостоятельный цикл мерцания пламени.
- Стенд измеряет нагрузку от Canvas-рисования спрайтов, но не учитывает ИИ, столкновения, взрывы и прочий код основной игры.
- Любое обновление `main` проходит через проверку GitHub Actions перед публикацией на GitHub Pages.
