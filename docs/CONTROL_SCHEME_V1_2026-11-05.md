# «Выживший»: единая схема управления

Дата: 5 ноября 2026 года. Действующий код: `arcade/control-layout.js`, `arcade/manual-weapon-controls.js`, `arcade/game.js`, `arcade/ship-weapons.js`. Публикация — только через `main` согласно `AGENTS.md`.

## Схема по умолчанию

| Действие | Управление | Почему |
| --- | --- | --- |
| Полёт | WASD; стрелки остаются альтернативой | Левая рука не отрывается от движения |
| Рывок | Левый Shift | Мизинец левой руки; независимо от мыши |
| Полевое устройство | Пробел | Большой палец; один тактический слот с перезарядкой |
| Взаимодействие и добыча | E, удерживать | Под указательным пальцем, отдельно от боя |
| Выстрел выбранного ручного орудия | ЛКМ | Точка прицеливания совпадает с курсором |
| Приоритет автоматическим орудиям | ПКМ | Однозначное действие даже при ручном огне |
| Смена ручного орудия | Колесо мыши | Только при двух доступных вариантах; не добавляет клавиш |
| Автоогонь вкл./выкл. | C | Нерегулярное решение, не нужно удерживать |
| Перепрограммирование | Q | Используется ситуативно |
| Авиаудар | B | Редкое действие со своим ресурсом |
| Карта | Tab | Привычная отдельная команда |
| Развитие | U | Открывает меню, не участвует в интенсивном бою |
| Гаубица без прицела | F | Дополнительный способ: система выбирает вражескую цель |
| Рельс: авто/ручной | R | Дополнительное переключение режима |

Клавиши можно изменить в раскрывающейся панели **«Клавиши»**. Используется `KeyboardEvent.code` (физическое положение клавиши); один код может относиться только к одному действию. Не назначаются зарезервированные системные и навигационные клавиши. Выбор хранится локально в `survivor.control-layout.v1`. Кнопка сброса восстанавливает весь стандартный набор. На время открытой панели игровой процесс приостанавливается, если он шёл.

## Что меняется с оружием

- **Пока ручное оружие недоступно**, ЛКМ также назначает приоритет автооружию, как в старой версии.
- **Рельс после открытия арсенала:** выбор рельса ещё не отключает автоматическую стрельбу. Первый сознательный выстрел ЛКМ переводит его в ручной режим; другие орудия продолжают стрелять автоматически. R позволяет вернуться к автоматическому огню из рельса.
- **Гаубица:** ЛКМ заряжает выстрел именно в точку курсора в пределах 900 м; снаряд летит физически, и цель может уйти. F и сенсорная кнопка сохраняют прежнее автоматическое наведение. Если установлены оба ручных орудия, колесо выбирает одно из них.
- **ПКМ:** всегда помечает либо снимает приоритет цели для автоматического оружия, независимо от выбора ручного ствола.
- **Полевой прибор:** пробел активирует установленный тактический прибор; установленный прокатный полевой модуль временно использует ту же клавишу. Отдельные кнопки для четырёх приборов не нужны.

На телефоне сохраняются сенсорный джойстик и кнопки действий. Касание врага по-прежнему назначает приоритет автоогню; установка гаубицы не превращает каждое касание в её выстрел. Прицельный рельс включается своей сенсорной кнопкой. Смена орудий колесом относится только к мыши.

## Проверка качества

- В `arcade/tests/unified-controls.test.mjs` проверены уникальность назначений, сохранение, запрет конфликтов, выбор ручного орудия, ручной выстрел рельса, прицел гаубицы, а также сохранение сенсорного управления.
- Общая регрессия: `node --test arcade/tests/*.test.mjs`.
- После публикации отдельно проверить в настоящем браузере переназначение клавиши, конфликт, сброс, реальный полёт, ручную стрельбу и поведение на мобильном устройстве. Автоматические проверки не доказывают удобство; его нужно проверить в боевом эпизоде продолжительностью 5–10 минут.
