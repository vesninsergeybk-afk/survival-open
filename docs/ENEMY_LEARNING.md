# Обучение противников в «Выжившем»

Дата: 4 ноября 2026 года. Реализация: `arcade/enemy-learning.js`, `arcade/ai.js`, `arcade/iris-choreography.js`, `arcade/game.js`.

## Что именно обучается

Игра накапливает результаты **реальных столкновений**, а затем выбирает успешнее показавший себя способ действия. Используется лёгкий многорукий бандит с исследованием альтернатив (UCB), а не нейросеть и не случайное изменение поведения. Обучение идёт прямо в браузере, без сервера и платного API.

Семь отдельных наборов тактик:

| Противник | Три варианта, между которыми учится выбирать |
| --- | --- |
| Разведчик IRIS (`scout`) | Манёвры с чередованием, более широкий разлёт, небольшое упреждение при ударе группы |
| Штурмовик (`fighter`) | Размашистый заход, упреждение движения игрока, прямой нажим |
| Перехватчик (`flanker`) | Обычная орбита, широкая орбита, заход с упреждением |
| Ремонтник (`healer`) | Ближайшая повреждённая цель, наиболее нуждающаяся в лечении, прикрытие восстанавливаемого корабля корпусом |
| Таранщик (`berserker`) | Прямое сближение, заход со смещением, упреждение движения |
| Корвет (`gunship`) | Обычная дальность боя, боковой манёвр на большей дистанции, сокращение дистанции |
| Турель (`turret`) | Стрельба по текущим координатам, ограниченное упреждение, упреждение с поправкой на поворот |

Для каждого типа независимо ведётся память о трёх ситуациях: игрок почти стоит, движется сравнительно прямо или часто меняет направление. Один и тот же рой может предпочесть разные приёмы при разных манерах пилотирования. При первом знакомстве система пробует все варианты; впоследствии предпочитает успешные, но иногда проверяет альтернативы. Старые результаты постепенно уступают место новым.

## Что считается успехом

- Фактически снятые с корабля игрока очки щита или корпуса; промахи не считаются попаданиями.
- Фактически восстановленные очки союзных кораблей для ремонтников.
- Сближение с видимым игроком в пределах боевой дистанции — лишь слабый дополнительный сигнал, чтобы корабли без дальнобойного оружия тоже могли учиться на манёврах.
- Полученные самим противником повреждения снижают оценку.
- Пустой пролёт без выстрела, урона, лечения или сближения не обучает модель.

Один вариант проверяется примерно 9,6 секунды. Снаряд сохраняет связь с тем вариантом, при котором его выпустили, поэтому даже попадание **после уничтожения стрелявшего корабля** учитывается правильно.

## Границы и честность

Алгоритм **не меняет здоровье, урон, скорость, частоту выстрелов, количество противников и вознаграждения**. Он выбирает только из предусмотренных разработчиком манёвров. Упреждение выстрелов ограничено; противник не знает будущее, не телепортируется и не получает скрытые координаты игрока через модель обучения. Для оценки движения игрока используются наблюдения противников в пределах видимости. Сюжетные приказы, уход патруля, задания на оборону объекта и поведение обращённых союзников выполняются по прежним правилам; в специально управляемых сценариях обучение манёвров не вмешивается.

Штурмовики и таранщики сохраняют правила предупредительной подготовки к опасному рывку. Группы IRIS сохраняют открытый коридор для ухода игрока, даже когда учатся перехватывать его движение. Исходное поведение остаётся допустимым вариантом на случай неудачного обучения.

## Память, проверка и сброс

Память хранится только в `localStorage` браузера, ключ `survivor.enemy-learning.v1`. Данные сохраняются по мере игры и при выходе со страницы. Для каждого способа действия число накопленных опытов ограничено — это предотвращает бесконтрольный рост памяти и позволяет сменить предпочтения после изменения стиля игры.

В консоли разработчика можно проверить накопленные данные:

```js
JSON.parse(localStorage.getItem('survivor.enemy-learning.v1'))
```

Для чистого сравнения поведения обученного и необученного роя можно удалить **только** этот ключ (сохранения корабля и экономики затронуты не будут):

```js
localStorage.removeItem('survivor.enemy-learning.v1')
```

После удаления ключа нужно перезагрузить игру. Поведение с незаполненной памятью будет исследовательским: каждое семейство противников сначала пробует разные тактики.

Автоматические проверки: `node --test arcade/tests/enemy-learning.test.mjs`; совместимость со всей игрой: `node --test arcade/tests/*.test.mjs`.

## Что пока нельзя утверждать

Тесты доказывают, что обратная связь записывается, сохраняется и меняет следующие решения, а также что разные решения действительно по-разному двигают корабли. Они **не доказывают**, что любой игрок станет проигрывать чаще или что рой уже достиг оптимальной тактики. Для этого нужны сравнительные игровые забеги на одинаковых условиях: с пустой памятью, с обучением и с замороженным набором тактик. Следующий балансировочный этап — измерить время жизни группы, долю попаданий, частоту получения урона игроком, долю успешных отступлений и частоту возникновения несправедливых ситуаций на мобильном устройстве.
