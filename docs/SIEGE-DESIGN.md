# Осада баз и баланс — «Выживший» 8.2

## Почему изменена логика турелей
Вместо запретной области вокруг изученного сектора враги теперь
иногда уклоняются от конкретного недавнего выстрела (окно 1,05 с).
Быстрые штурмовики получают небольшую вероятность частичного
уклонения; турель всё равно может по ним попасть. Перегрев остаётся.

## Локальное событие «Осада»
- Первое предупреждение не ранее 385 секунд, при уровне 6; если
  уровень ниже, событие возможно после 485 секунд.
- Предупреждение за 34 секунды; отсчёт останавливается, если игрок
  дальше 790 игровых единиц от защищаемой базы.
- При уходе дальше 860 единиц бомбардировка приостанавливается;
  при удалении свыше 950 единиц в течение 7 секунд налёт заканчивается
  без награды. Далёкие базы не погибают сами по себе.
- Первая волна: 2 тяжёлых бомбардировщика и 3 корабля прикрытия.
  Эскадрилья растёт постепенно. Бомбардировщики стреляют с дистанции
  205 единиц, наносят 22+ единицы урона базе за выстрел.
- Для победы надо перехватить группу; награда: 56–84 кредита.
  Если база уничтожена, другие базы остаются доступными.
- Следующий налёт не ранее чем через 185 с после победы.

## Ракеты игрока
- «Ракетный залп»: 1/2/3 ракеты на уровнях 1–2/3–4/5.
- Базовая перезарядка 1,22 секунды вместо 0,4; дальность 300
  вместо 420, скорость 470 вместо 620; пробитие всех целей убрано.
- Базовый урон одной ракеты увеличен до 19 вместо 12,
  чтобы точное попадание оставалось полезным.

## Следующая проверка по реальным забегам
Смотреть: время первой осады, потери базы без участия игрока,
долю убитых турелями штурмовиков, уровень ракет на 5–8-й минуте,
не возникают ли повторные скопления врагов у границы сектора.
