# «Выживший»: адаптация противников — три проверяемых прохода

Дата: 4 ноября 2026 года. Исходная игра: `survival-open/arcade/` в единственном основном репозитории.

## Зачем

У игрока сохраняются простые средства управления: движение, рывок, автоматическое оружие, добыча, развитие корабля и взаимодействие с базами. Противники могут менять построение, только если действительно узнали о действиях игрока. Игрок видит причину смены стратегии, полученный приказ и соответствующий манёвр.

## Проход 1. Достоверные сведения

- Корабль обнаруживает игрока в пределах своего обычного датчика при свободной линии обзора. Проверки распределены по времени, чтобы не запускать сотни проверок преград за кадр.
- При потере контакта корабль идёт к последней известной точке, а затем ищет в её окрестностях. Координаты игрока в этот момент не обновляются тайно.
- Вновь прибывший отряд может получить координаты диспетчера на момент вылета; это не постоянная слежка.
- Патрули, прибывшие на шум добычи, хранят сведения по отдельности. Другой корабль переходит к преследованию после подтверждённой радиопередачи.
- Сведения по связи имеют срок годности. Обрыв передачи и уничтожение командира прекращают совместное исполнение приказов.
- При попадании из-за пределов прямой видимости корабль оценивает примерный сектор, откуда пришёл выстрел, по направлению удара. Только два разнесённых по времени сообщения дают отряду основание заняться этим сектором. Точная позиция и текущая скорость игрока из попадания не выводятся.
- Наблюдение за манёврами игрока принадлежит конкретному пилоту или турели. Остальные могут узнать его характер лишь по полученному радиодонесению; общая база успешности тактик сохраняется без мгновенного обмена координатами.

**Контроль:** сценарии с закрытым астероидом обзором, уходом игрока после обнаружения, отключённой радиосвязью и 200 кораблями.

## Проход 2. Осмысленная тактика и выбор игрока

- Вражеский пилот распознаёт вид оружия по фактическому попаданию, приблизительно оценивает расстояние до стрелявшего корабля и отправляет сообщение командиру. У него нет доступа к списку установленных модулей игрока.
- Группа не перестраивается по одному попаданию: нужны минимум два сообщения об одном признаке, разделённые не менее чем 0,9 секунды. Наблюдения стареют и перестают влиять на решения.
- При смене оружия старый подтверждённый признак уступает более свежему; площадное оружие не остаётся пожизненным приоритетом.
- **Дальний огонь:** группа выбирает сокращение дистанции. **Площадные удары:** корабли рассредоточиваются. **Сближение игрока:** прежнее голосование слегка чаще предпочитает обход. Остальные режимы — перехват, нажим и прикрытие ремонтника — сохраняются.
- Манёвр меняет реальные точки движения. Он не повышает здоровье, урон, запас выстрелов и предельную скорость кораблей.
- Повреждённые и охраняющие ремонтника корабли сохраняют прежние обязанности. Командир не объявляет строевой манёвр, если нет подчинённого, который способен его выполнить. Сообщение считается подтверждённым лишь после фактического изменения движения.
- Если группа собственными датчиками видела гибель двух машин и успела передать сведения командиру, выжившие временно рассредоточиваются. Один взрыв или чужой, невидимый бой не запускает такую реакцию. Командир не создаёт подкреплений и не меняет характеристики бойцов.
- Нажатие на видимую враждебную цель меняет приоритет автооружия на 14 секунд. Повторное нажатие снимает отметку. Дальность, препятствия, стоимость и скорость стрельбы не меняются; скрытый патруль нельзя отметить.

**Контроль:** идентичные начальные позиции при разных приказах; одиночное попадание без перестроения; два подтверждённых сообщения с новым строем; невозможность отметить невидимого или слишком далёкого противника; прежняя эффективность автооружия без выбора цели.

## Проход 3. Видимая реакция мира

- Внутри мира прорисованы действительные импульсы радиообмена. Короткие стрелки показывают только реально выполняемый приказ.
- После реального выполнения нового приказа командир ненадолго показывает текст радиоперехвата. Для дальнего оружия, площадных атак и подтверждённых потерь текст объясняет наблюдаемую причину.
- Радиоперехват возможен на дистанции до 560 игровых единиц, даже если командир за препятствием. В этом случае игрок получает краткое текстовое уведомление и запись на карте, но не точные координаты подразделения. Подпись рядом с кораблём возникает лишь при прямой видимости командира.
- Число линий, подписей, сообщений и хранимых наблюдений ограничено. Линии действующей связи сделаны различимее при низкой частоте кадров; невидимые корабли не рисуют подсказок сквозь укрытия.

**Контроль:** сообщение соответствует установленному приказу; пропадает после отведённого времени; не возникает без доставки; не раскрывает скрытые подразделения; карта показывает только собранные игроком сведения.

## Ограничения, которые сохраняются специально

- Регионы, вражеские базы и снабжение уже существуют в других подсистемах. Текущий проход не создаёт фиктивной глобальной памяти регионов: её нужно связать с действительными ретрансляторами, конвоями и станциями после отдельной проверки экономических последствий.
- Для подавления радиосвязи нет бесплатной новой кнопки. Если вводить глушитель, это должен быть устанавливаемый модуль с расходом ресурсов и понятной заменой другому оснащению.
- Ускорение противников, увеличение их урона, принудительное попадание и невидимые подкрепления не используются как «награда» за обучение.
- Автоматические проверки подтверждают всю цепочку от реального повреждения корабля до оценки сектора, решения, выполнения приказа и перехвата. Увлекательность, читаемость на телефоне, частота сообщений и сложность после долгой игры требуют отдельного прохождения людьми.

## Контроль при публикации

1. `node --test arcade/tests/*.test.mjs`
2. `node audio-lab/smoke-test.mjs`
3. GitHub Actions `Publish Survivor arcade`, проверка сборки модулей и ресурсов.
4. Ручная проверка: два дальних попадания по живучему отряду вызывают приказ о сближении даже за пределами обычной видимости; попадание не раскрывает точные координаты; гибель двух машин на глазах группы вызывает рассредоточение; уничтожение командира обрывает радиоприказы примерно на две секунды; новая цель выбирается мышью либо касанием; карта показывает лишь услышанные приказы. Проверить читаемость сообщений на телефоне и при 20 кадрах в секунду.

Публикация — только из `main` по адресу <https://vesninsergeybk-afk.github.io/survival-open/arcade/>. Страница <https://vesninmed.ru/lab/> остаётся единой внешней точкой входа.
